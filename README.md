# 调用方 Codex：从这里开始

这是客服机器人配置开发的公开方法仓库。当前方法包版本：`a6ce1ac24aa10702`。[版本声明](./latest.json)指向[新人启动包](./releases/a6ce1ac24aa107029a82b8413b068973a1df3f7b95edf6244b090cd7265334aa/startup.zip)。仓库不包含客户资料、工作包或 Token。

## 给新人的唯一入口

把本仓库地址交给自己电脑上的 Codex，并发送：

```text
请从这个 GitHub 仓库获取并校验最新版 AI 客服机器人新人启动包，在我的电脑建立独立的本地项目。你负责读取包内规则、随包 Skill、平台接口契约和练习案例，并按任务需要调用本机可用的其他 Skill，直接开始“星禾口语课程咨询”的配置练习；请自行完成可在本地完成的步骤。需要测试环境 Token、独立练习 Bot、真实会话入口或业务确认时，只告诉我当前缺少的具体条件。不要让我逐页阅读操作手册，也不要把本地演练说成线上闭环通过。
```

## Codex 执行入口

1. 读取[引导脚本](./bootstrap.py)，核对其 SHA-256 为 `847cb5be23713ea47a9730a9d62799ca011a12a98947b81c1b80f9136f024496`，再用本机 Python 3.11 执行 `bootstrap.py --output-root <新人自己的工作目录>`。脚本从本仓库 `main/latest.json` 取得当前 ZIP，核对字节数、SHA-256、包内清单和路径后解压，并输出本地项目路径；任一校验失败即停止。没有脚本运行条件时，可按同一契约自行执行这些检查。
2. 在新人电脑建立独立工作目录，按原路径解压 ZIP，保留隐藏的 `.agents/skills/`。已有同名项目或客户文件时不要覆盖；先核对当前版本和目录，再选择新目录或按包内同步工具更新通用文件。将内层 `AI客服机器人交付中心` 作为 Codex 本地项目。
3. 读取包外 `先看这里.md`，再读项目内 `AGENTS.md`、`配置交付SOP链路.md`、随包 Skill、`平台接口/第二阶段-20261003/` 的三份当前契约、`练习案例/练习任务.md` 和联调工具 README。按文件类型与实际工作选用本机已可用的资料处理 Skill；新 Codex 自行执行可用性检查，不要求新人代读这些文件。
4. 直接从虚构案例开始：在 `练习/星禾口语课程咨询/` 保存 SOP、已确认与待确认事实、跨板块变更计划和测试记录。管理员提供测试环境 ready Bot 与员工 Token 后，按当前 Bot 列表由员工明确选目标，导出可信工作包，再在独立工作副本修改 Agent、知识库、状态机和按需启用的标签；完成静态检查。
5. 隔离练习 Bot、真实会话入口和发布条件具备后，按第二阶段契约分步上传、预检、审阅 diff、发布、回读、实测与回退。预检有 blocker 就停止并记录证据。负责人审核完整练习通过后才开始真实客户任务；正式环境写入默认关闭。

新人不必理解接口细节或手册，Codex 应按项目 Skill 与契约执行。外部条件未齐时，先完成不依赖它们的真实本地练习，并准确记录尚未验证的环节。

## 方法更新

`latest.json` 指向当前校验版本，`releases/` 保留历史版本。后续通用方法通过项目内 `工具/经验同步/` 更新；脱敏反馈只向另行配置的私有反馈仓库提交，未接通时留在本机。客户资料、配置、工作包和凭据始终留在各自私有目录。

管理员侧接口协作背景见[调用方 Codex 与接口平台对接任务](调用方Codex与接口平台对接任务.md)。
