# AI 客服交付方法与经验同步

这是调用方 Codex 的客服配置方法仓库。当前方法包版本：`977320f490df4845`。

[下载当前新人启动包](./releases/977320f490df48452ac5851e8f9b610c5aa51e1817891e3c14c708457e60da6c/startup.zip)；[查看版本摘要](./latest.json)。下载后先阅读包内 `先看这里.md`，把内层 `AI客服机器人交付中心` 文件夹添加为自己的 Codex 本地项目。

## 新人上手

1. 读取包内两个核心 Skill、`平台接口/` 当前文档及 `练习案例/`。
2. 管理员准备测试环境练习 Bot 后，从该环境的 Bot 列表明确选择，导出并校验可信工作包。
3. 用虚构的“星禾口语课程咨询”完成跨板块本地配置和检查；负责人按验收表审核。
4. 审核通过后，再为真实客户选择其所在环境的 Bot，重新导出该 Bot 的当前工作包；测试与正式环境管理不同 Bot，基线不能混用。

当前接口只开放身份、能力目录、Bot 列表、配置上下文和可信工作包导出。上传、预检、差异与冲突、联合发布、回读、Release 查询及回滚作为第二阶段整体开放；管理员正式通知前不构造或调用写接口。

## 方法更新与反馈

`latest.json` 指向已校验的当前包，`releases/` 保留不可覆盖的历史版本。公开仓库用于方法包发布和下载。脱敏经验只向单独配置的私有反馈仓库回传；尚未接通时留在新人本机队列，客户任务继续使用本机方法。原始客户资料、配置、工作包和凭据不进入本仓库。

管理员侧接口协作背景见[调用方 Codex 与接口平台对接任务](调用方Codex与接口平台对接任务.md)。
