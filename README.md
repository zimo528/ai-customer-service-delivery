# AI 客服交付方法与经验同步

团队使用的通用交付方法、Skill 版本与脱敏测试经验共享通道。

## 开始使用

由仓库所有者提供新人启动包并授予访问权限。按包内“先看这里.md”在自己的电脑添加本地项目，登录 GitHub，以 worker 角色初始化经验同步，并在自己的总控对话启用每小时提交和检查新版的方法同步。

`latest.json` 指向当前已校验的方法包，`releases/` 保留已发布版本。经验通过带固定标记和唯一编号的 Issue 回传，原始客户资料、客户配置与账号凭据保存在各自本机。统一主控在原总控对话复核证据、更新对应 Skill，再校验并发布。

不改变业务含义的已验证方法改进可自动处理；业务规则变化仍按原有人工确认关口执行。实际采用与发布结果记录在反馈 Issue 中。

本地定时任务需要电脑开机、Codex 运行、项目与 Git 登录可用。断网时本地队列保留，恢复后重试。机器人配置自动上传后台按项目原约定单独接入。
